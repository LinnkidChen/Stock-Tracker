# Agent Methodology Index

This directory defines the Trellis-first adapter rules that borrow selected methodology from Superpowers without running Superpowers as a competing workflow controller.

- `superpowers-adapter.md` - precedence and conflict rules.
- `planning.md` - implementation planning rules for Trellis tasks.
- `tdd.md` - test-first implementation gate.
- `debugging.md` - systematic root-cause debugging gate.
- `verification.md` - evidence-before-claims completion gate.
- `review.md` - review cadence and severity handling.

Trellis owns task lifecycle, specs, workspace journals, context injection, update-spec, check, and finish-work.

Superpowers contributes only patterns and quality gates.
