# 数据模型

## 实体

### 股票代码

- **含义**: 用户请求的股票标识。
- **关键字段**:
  - `symbol`: 大写字母与数字组成的字符串。
- **校验规则**:
  - 必填；格式不合法时返回参数错误。

### 数据来源

- **含义**: 报价或 K 线数据的提供方标识。
- **关键字段**:
  - `provider`: 字符串；为空时使用默认值。
- **校验规则**:
  - 允许为空或未知值；若不支持需返回可区分错误。

### 报价结果

- **含义**: 报价接口成功返回的数据。
- **关键字段**:
  - `symbol`, `price`, `open`, `high`, `low`, `volume`, `previousClose`, `lastUpdated`。
- **关系**:
  - 关联一个股票代码与一个数据来源。

### K 线序列

- **含义**: K 线接口成功返回的数据。
- **关键字段**:
  - `symbol`, `range`, `candles[]`, `lastUpdated`。
- **关系**:
  - 关联一个股票代码与一个数据来源。

### API 错误

- **含义**: 请求失败时返回的错误结果。
- **关键字段**:
  - `code`, `message`, `details`（可选）。
- **状态转移**:
  - 校验失败 → 参数错误
  - 权限或上游失败 → 对应错误类型
  - 未知异常 → 统一错误类型
