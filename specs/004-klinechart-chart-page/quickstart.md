# 快速开始: K线图表独立页与导航

## 目标

验证图表页已拆分为独立页面，且可从仪表盘概览区域进入并正常显示 K 线图表状态。

## 前置条件

- 本地可启动项目（`pnpm dev`）
- 具备可登录的账号（沿用现有认证机制）

## 手动验证步骤

1. 启动开发服务并登录。
2. 打开仪表盘页面（`/dashboard/stocks`），确认不再显示旧的价格图表区域。
3. 在“Market Overview”下方找到图表导航卡片并点击。
4. 确认跳转到独立图表页并展示页面主体。
5. 选择/输入有效标的（例如 `AAPL`），确认 2 秒内显示 K 线图表或加载状态。
6. 切换到另一个标的，确认图表更新并展示最新状态。
7. 输入无效标的，确认页面显示错误提示且不崩溃。

## API 快速验证（可选）

- `GET /api/stocks/kline/AAPL` 应返回成功的 K 线数据响应
- `GET /api/stocks/quote/AAPL` 应返回成功的行情数据响应

## 预期结果

- 图表页与仪表盘解耦，入口清晰可见
- K 线图表在有效标的下可正常渲染，错误与空数据状态可识别
